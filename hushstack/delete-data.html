앱 이름: Hushstack · 최종 수정일: 2026-10-07

Hushstack은 회원가입이 없는 게임입니다. 계정이 없으므로 삭제할 계정도 없습니다. 다만 이용자가 순위표에 직접 이름을 남긴 경우, 그 이름과 점수가 순위 집계를 위해 서버에 저장됩니다. 이 기록은 아래 방법으로 삭제를 요청하실 수 있습니다.

삭제를 요청하는 방법

이메일 한 통이면 됩니다.

  1. nobrain1988@gmail.com 으로 메일을 보냅니다.
  2. 제목에 “Hushstack 기록 삭제 요청” 이라고 적습니다.
  3. 본문에 순위표에 남기신 이름(별명)을 적습니다.
    예: “제가 남긴 이름은 한칸더 입니다. 삭제해 주세요.”
  4. 7일 이내에 삭제하고 회신해 드립니다.

별명은 10자 이내이며 실명이 아닙니다. 같은 별명이 여러 개인 경우를 대비해 대략적인 점수나 기록한 시기를 함께 적어주시면 더 정확합니다.

Hushstack — Request Data Deletion

App name: Hushstack · Last updated: 2026-10-07

Hushstack has no sign-up, so there is no account to delete. If you chose to put your name on the leaderboard, that display name and score are stored on a server so the ranking can be compiled. You can ask us to delete that record using the steps below.

How to request deletion

One email is all it takes.

  1. Email nobrain1988@gmail.com.
  2. Use the subject line “Hushstack data deletion request”.
  3. In the body, give the display name you entered on the leaderboard.
    For example: “The name I entered is OneMoreRow. Please delete it.”
  4. We delete it within 7 days and reply to confirm.

Display names are up to 10 characters and are not real names. If several entries share a name, adding an approximate score or when you played helps us find the right one.

What is deleted and what is kept

Data What happens Retention
Leaderboard display name Permanently deleted on request Deleted within 7 days of the request. Not retained afterwards, and no separate backup copy is kept.
Leaderboard score Permanently deleted with the name Same as above
On-device data
(best score, sound setting)		 Never sent to a server Gone the moment you uninstall the app. No request needed.
Advertising ID This app neither stores nor retains it Governed by Google AdMob. You can reset it on your device under Settings → Google → Ads → Delete advertising ID.
Real name, email, phone, location, contacts Never collected in the first place. There is nothing to delete.

Deleting your leaderboard record does not affect your ability to keep playing; entering a name again creates a new entry.
